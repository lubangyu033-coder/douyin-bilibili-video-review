# 中文使用说明

这是给 Codex、DeepSeek Harness 等助手的一套视频资料审查流程。你可以给公开抖音/B 站链接，也可给已有本地视频、字幕或截图。助手应说明实际看到了哪些内容，再整理要点。

## 按需要配置任务

可以直接复制这个模板；不填写的项目按技能默认设置执行：

~~~text
请使用这个 skill 审查以下视频：
链接或本地文件：
目标：提取主要论点 / 操作步骤 / 工具清单 / 对比差异
时间范围：可访问的整段，或指定起止时间
深度：常规 / 只读页面资料 / 重点逐段检查
本地处理：使用已有工具；如缺依赖或模型，先报告
外部核验：需要核对的具体主张
输出：逐条笔记 / 表格 / 对比表 / 资料卡
~~~

Codex 可先输入 `$douyin-bilibili-video-review`，Harness 可输入 `/douyin-bilibili-video-review`。先按 [安装指南](INSTALL.md) 放置文件。

## 需要哪些能力

如果只审查页面，使用当前会话已有的浏览器或网页工具即可。若对方电脑不能访问视频，它可以整理可读页面、字幕或你提供的资料，并说明缺口。

本地处理是可选配置：Python 依赖用于探测和生成字幕墙；已有 CT2 Whisper 模型用于 ASR。随包脚本及全部参数见 [本地处理说明](references/local-processing.md)。脚本不会自动取视频、装软件或下载模型。

DeepSeek Harness 的技能目录、同名覆盖、调用开关以及近期 Search/Fetch 功能，见 [Harness 配置](references/deepseek-harness.md)。普通 DeepSeek 网页或 App 不会因拿到技能文件就拥有这些本地工具。

## 怎样读结果

结果应包含原链接、实际查看区间、音频/字幕状态、带时间点的要点、可用资料和待核项。页面摘要、评论、ASR 都应标注来源；作者声称的效果或收入不自动成为事实。

字幕墙是带时间点的裁剪图片，仍需读取和回看原帧。ASR 是可能出错的口播草稿；跑完全部音频不代表画面也全部审过。字幕与 ASR 相互冲突时，应回查音频和画面；没办法核对就保留疑点。

本次移植和验证情况见 [能力记录](capabilities.md)。
